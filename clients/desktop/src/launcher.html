Run FreeBooks on this computer

A local server keeps your books and attachments on this computer. Install Docker Desktop (or Docker Engine with Compose) and Python 3.11+ first. The initial build needs internet access, several gigabytes of storage, and may take several minutes.



Create the first local owner
For a fresh local installation only. Public sign-ups stay closed. These credentials are sent only to your local setup tool and are not saved in server profiles.


Closing this app leaves the local server running. Back up your server before upgrading. Desktop alpha has no auto-update, signed installer, or native embedded database.
