Get your own workspace running

For self-hosting, extract the source archive and run these commands from its root directory:

python3 deploy/beta/manage.py init
python3 deploy/beta/manage.py start --build
python3 deploy/beta/manage.py owner
python3 deploy/beta/manage.py check

Open the localhost address printed by the installer and complete organization setup. Public signup stays closed; bootstrap temporarily allowlists only your chosen owner email.

How local desktop mode works

  1. Install and start Docker with Compose v2, plus Python 3.11 or newer.
  2. Extract the desktop package, open the launcher and choose Set up / start local server.
  3. Create your owner, open My local FreeBooks and finish organization setup.

The complete backend runs in local Docker services. Records live in Docker volumes. Initial setup downloads dependencies and builds the server; external connections use the internet when enabled.

For remote-server mode, enter the server's HTTPS address. Its operator controls accounts, data and provider configuration.

Connect with clear expectations

Bank feeds and payment services require your own provider account, approved live credentials, permissions and institution support. Saved credentials alone do not confirm a working import.

Connection and accounting features are in alpha; universal provider coverage has not been verified. CSV imports and source-document uploads remain useful for building an independent record.

Review category suggestions, account mappings, large payments, transfers and tax treatment. The workspace helps organize evidence; final accounting decisions remain inspectable.
